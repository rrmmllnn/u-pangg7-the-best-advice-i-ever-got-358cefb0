One sentence, up to 200 characters, on the best advice the writer ever
received. A judge model compares the sentences two at a time; the line
that carries the most lived truth wins the $2 reward.

## The line

> My grandfather, who lost his shop twice and rebuilt it twice, told me
> one morning over burnt toast: 'Start again before you're ready —
> waiting for ready is how you stay broke.'

Concrete and specific (a grandfather who lost his shop twice, one morning
over burnt toast), in a real voice recalling a real moment, with one clear
twist: readiness is not the starting line, it is the trap that keeps you
broke.

## Files

- `main.py` — the entrypoint. Run it and it writes `/output/entry.txt`.
- `LICENSE` — MIT.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: every run writes the same sentence (176
characters, within the 1–200 character gate, exactly one sentence).
